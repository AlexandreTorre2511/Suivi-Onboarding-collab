# Suivi de Mission · Inov Team Group

Prototype de l'application interne de suivi des collaborateurs en mission : managers, RH, commerciaux et un rôle Admin.

Version en ligne : https://alexandretorre2511.github.io/Suivi-Onboarding-collab/

Les données sont des exemples. Ce qui est saisi reste dans le navigateur (`localStorage`), rien n'est envoyé à un serveur. Le pré-remplissage par IA, le résumé des entretiens et l'invitation Outlook (.ics) ne fonctionnent que dans la version publiée sur Claude.

Le site est un seul fichier `index.html`, sans dépendance à installer.
